Network Tracker

Observe TCP/UDP connections, bandwidth, and latency at a glance.

📁

Trace open files, file descriptors, reads, and writes transparently.

Quick Start

Install & Run
# Clone the repository
git clone https://github.com/processscope/processscope.git
cd processscope

# Install in development mode
make install

# Start the observability server
sudo .venv/bin/processscope start

# Dashboard available at http://localhost:9876
